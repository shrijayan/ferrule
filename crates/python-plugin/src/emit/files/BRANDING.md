# Branding substitutions in project files

The plan forbids Stainless branding in what Ferrule ships, so generated text that names
Stainless as the generator says Ferrule instead. These lines are the only allowed diffs against
the oracle in the project-file oracle tests: `tests/files_oracle.rs` (OneBusAway) and
`tests/project_files_oracles.rs` (isaacus, lumaai, imagekit) hold the same list.

## Substituted

| File | Oracle text | Ferrule text |
|------|-------------|--------------|
| every generated `.py` file (tests/**) | `# File generated from our OpenAPI spec by Stainless. See CONTRIBUTING.md for details.` | `... by Ferrule. ...` (same as `HEADER` in `src/emit/common.ts`) |
| `examples/.keep` | `File generated from our OpenAPI spec by Stainless.` | `File generated from our OpenAPI spec by Ferrule.` |
| `examples/.keep` | `It is ignored by Stainless code generation` | `It is ignored by Ferrule code generation` |
| `README.md` | `It is generated with [Stainless](https://www.stainless.com/).` | `It is generated with Ferrule.` |
| `SECURITY.md` | `This SDK is generated by [Stainless Software Inc](http://stainless.com). Stainless takes security seriously, and encourages you to report ...` | `This SDK is generated by Ferrule. We take security seriously, and encourage you to report ...` |
| `SECURITY.md` | `To report a security issue, please contact the Stainless team at security@stainless.com.` | `To report a security issue in this SDK, please contact the maintainers listed under Terms and Policies below.` |
| `.github/workflows/ci.yml` (3 jobs) | `runs-on: ${{ startsWith(github.repository, 'stainless-sdks/') && 'depot-ubuntu-24.04' \|\| 'ubuntu-latest' }}` (isaacus: `github.repository == 'stainless-sdks/isaacus-python' && ...`) | `runs-on: ubuntu-latest` |
| `.github/workflows/ci.yml` (build job) | steps "Get GitHub OIDC Token" and "Upload tarball" (run only in `stainless-sdks/*` repos, upload to `pkg.stainless.com`) | removed |

## Dropped files

| File | Why |
|------|-----|
| `scripts/utils/upload-artifact.sh` | Uploads builds to Stainless's package storage; only the removed CI steps call it. |

## Dropped README sections

| Section | Why |
|---------|-----|
| `## MCP Server` (isaacus) | Installs the MCP server Stainless builds from `targets.typescript.options.mcp_server`, through `vscode.stainless.com`; Ferrule generates no MCP server. |
| `## Nested params` (isaacus, lumaai) | Its example is `readme.example_requests.nested_params` (isaacus) or one Stainless picks from the request examples (lumaai); Ferrule reads neither yet: a gap, not a choice. |

`readme.include_stainless_attribution: false` (lumaai, imagekit) leaves out the
"It is generated with ..." line, as Stainless does.

## Kept on purpose

These mention Stainless but are not branding of the generator, so they stay byte-identical:

- `X-Stainless-Lang`, `x-stainless-retry-count` and the other `X-Stainless-*` headers in
  `tests/test_client.py` and `tests/api_resources/**`: they are the runtime's wire protocol
  (owned by `runtime/`), and the tests check what the runtime sends. If the runtime renames
  them, the templates follow.
- `"stainless"` as an arbitrary test value in `tests/test_client.py` and `tests/test_transform.py`.
- `release-please-config.json` `$schema`: a working URL of the release-please fork's schema.
- `.github/workflows/ci.yml` branch filters `stl-preview-*` and `codegen/stl/**`: inert in an
  SDK repository; kept so the workflow matches the oracle.
- `.stats.yml` `openapi_spec_url`: an input value, emitted as given.
