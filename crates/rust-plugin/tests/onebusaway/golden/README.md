# onebusaway-sdk

Rust SDK for the OneBusAway API.

Generated by Ferrule from the API's OpenAPI spec and `stainless.yml`.

## Install

```toml
[dependencies]
onebusaway-sdk = "0.0.2"
```

The `blocking` feature adds a client whose calls block; `testing` adds a fake server.

## Usage

```rust,no_run
use onebusaway_sdk::OnebusawaySdk;

#[tokio::main]
async fn main() -> Result<(), onebusaway_sdk::Error> {
    let client = OnebusawaySdk::builder()
        .api_key("My API Key")
        .build()?;
    let response = client.agencies_with_coverage().list().await?;
    println!("{response:?}");
    Ok(())
}
```

Each option the builder does not set is read from the environment, so `OnebusawaySdk::new()` works
when the environment has them.

## Requests

A method takes its required params as arguments and returns a request: set its optional params,
then `.await` it (or call `send()`). `request_timeout`, `request_max_retries`, `extra_header` and
`extra_query` change one request.

List methods return a `Page`; `paginate()` gives a `Stream` of every item of every page.
Streaming methods return a `Stream` of events.

## Errors

Every call returns `Result<T, onebusaway_sdk::Error>`. A status that is not 2xx gives the variant of its
status (`NotFound`, `RateLimit`, …) with the status, headers and body; `Connection`, `Timeout` and
`Decode` say why no response could be read.

## Retries and timeouts

Connection errors, timeouts, 408, 409, 429 and 5xx responses are retried with exponential backoff,
2 times by default (`max_retries`). A request times out after 60 seconds by default
(`timeout`).

## Blocking client

With the `blocking` feature, `OnebusawaySdkBuilder::build_blocking()` gives `onebusaway_sdk::blocking::OnebusawaySdk`,
whose requests block on `send()`.
