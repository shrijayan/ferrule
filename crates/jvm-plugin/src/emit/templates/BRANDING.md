# Branding substitutions in the JVM SDK

As for Python (`crates/python-plugin/src/emit/files/BRANDING.md`), generated text that names
Stainless as the generator says Ferrule instead. These are the only allowed differences from
the oracles in `tests/oracle.rs`; `tests/common/mod.rs` (`brand`) applies the same list to the
oracle's text before comparing.

## Substituted

| File | Oracle text | Ferrule text |
|------|-------------|--------------|
| every generated `.kt` file | `// File generated from our OpenAPI spec by Stainless.` | `... by Ferrule.` (`HEADER` in `src/kt.rs`) |
| `<artifact>-lib/.keep`, `examples/.keep` (Java) | `File generated from our OpenAPI spec by Stainless.`, `It is ignored by Stainless code generation` | `... by Ferrule.`, `It is ignored by Ferrule code generation` |
| `SECURITY.md` | `This SDK is generated by [Stainless Software Inc](http://stainless.com). Stainless takes security seriously, and encourages you to report ...` | `This SDK is generated by Ferrule. We take security seriously, and encourage you to report ...` |
| `SECURITY.md` | `To report a security issue, please contact the Stainless team at security@stainless.com.` | `To report a security issue in this SDK, please contact the maintainers listed under Terms and Policies below.` |
| `.github/workflows/ci.yml` (3 jobs) | `runs-on: ${{ startsWith(github.repository, 'stainless-sdks/') && 'depot-ubuntu-24.04' \|\| 'ubuntu-latest' }}` | `runs-on: ubuntu-latest` |
| `.github/workflows/ci.yml` (build job, Java) | steps "Get GitHub OIDC Token" and "Build and upload Maven artifacts" (run only in `stainless-sdks/*` repos, upload to `pkg.stainless.com`) | removed |

## Dropped files

| File | Why |
|------|-----|
| `scripts/upload-artifacts` (Java) | Uploads builds to Stainless's package storage; only the removed CI steps call it. |

## Kept on purpose

- The `X-Stainless-*` request headers in `core/ClientOptions.kt`: the runtime's wire protocol.
- `release-please-config.json` `$schema`: a working URL of the release-please fork's schema.
- `.github/workflows/ci.yml` branch filters `stl-preview-*` and `codegen/stl/**`: inert in an
  SDK repository; kept so the workflow matches the oracle.
