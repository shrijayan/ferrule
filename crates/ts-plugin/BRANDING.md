# Branding substitutions in the TypeScript SDK

As for Python (`crates/python-plugin/src/emit/files/BRANDING.md`), generated text that names
Stainless as the generator says Ferrule instead. These are the only allowed differences against
the oracle; `tests/support/mod.rs` (`BRANDING`, `brand_ci`) applies the same list to the oracle
before comparing.

## Substituted

| File | Oracle text | Ferrule text |
|------|-------------|--------------|
| every generated `.ts` file (`src/**`, `tests/**`) | `// File generated from our OpenAPI spec by Stainless. See CONTRIBUTING.md for details.` | `... by Ferrule. ...` (`HEADER` in `src/emit/mod.rs`) |
| `examples/.keep`, `src/lib/.keep` | `File generated from our OpenAPI spec by Stainless.` | `... by Ferrule.` |
| `examples/.keep`, `src/lib/.keep` | `It is ignored by Stainless code generation` | `It is ignored by Ferrule code generation` |
| `README.md` | `It is generated with [Stainless](https://www.stainless.com/).` | `It is generated with Ferrule.` |
| `SECURITY.md` | `This SDK is generated by [Stainless Software Inc](http://stainless.com). Stainless takes security seriously, and encourages you to report ...` | `This SDK is generated by Ferrule. We take security seriously, and encourage you to report ...` |
| `SECURITY.md` | `To report a security issue, please contact the Stainless team at security@stainless.com.` | `To report a security issue in this SDK, please contact the maintainers listed under Terms and Policies below.` |
| `.github/workflows/ci.yml` (every job) | `runs-on: ${{ github.repository == 'stainless-sdks/<project>' && 'depot-ubuntu-24.04' \|\| 'ubuntu-latest' }}` | `runs-on: ubuntu-latest` |
| `.github/workflows/ci.yml` (build job) | steps "Get GitHub OIDC Token", "Upload tarball" and "Upload MCP Server tarball" (run only in `stainless-sdks/*`, upload to `pkg.stainless.com`) | removed |

## Dropped files

| File | Why |
|------|-----|
| `scripts/utils/upload-artifact.sh` | Uploads builds to Stainless's package storage; only the removed CI steps call it. |

## Kept on purpose

- `X-Stainless-*` headers in `tests/index.test.ts`: the runtime's wire protocol.
- `https://github.com/stainless-api/tsc-multi/...` in `package.json`, the `stainless-api/sdk-assets`
  images in `README.md` and the release-please schema URL: working URLs of build inputs.
- The `vscode.stainless.com/mcp/...` install link of the README's MCP section: a working
  redirect for the MCP server Stainless publishes for the SDK.
- `.github/workflows/ci.yml` branch filters `stl-preview-*`: inert in an SDK repository.
- `.stats.yml` `openapi_spec_url`: an input value, emitted as given.
